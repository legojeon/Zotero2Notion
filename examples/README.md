# Worked examples

[Open the public Notion template](https://sleepy-hamster-e60.notion.site/Zsotero2Notion-Journal-DB-400cf80747f2804b99e3db09641b7368) to duplicate the database with both examples.

Two English examples for the bundled Markdown templates. These are completed reading notes; the files in `addon/templates/` remain reusable blank frames.

| Template | Example | Notion page |
|---|---|---|
| Section summary | [Attention Is All You Need](attention-is-all-you-need.md) | [Open example](https://app.notion.com/p/400cf80747f2817a8d71f4a61e979c26) |
| Paper review | [Deep Residual Learning for Image Recognition](resnet-paper-review.md) | [Open example](https://app.notion.com/p/400cf80747f28182ae9fead8e4e00087) |

The section summary follows the published paper's headings; the general-purpose blank template uses common section names that can be renamed. The critical review organizes the problem, proposal, evidence, limitations, and reader takeaways. Reader questions and takeaways are explicitly labeled examples, not statements of the owner's views.

Sources are linked in each note, with section/table references for checking the claims. Numerical tables were checked against the original PDF pages. ResNet notes refer to arXiv:1512.03385v1 (2015); bibliographic metadata uses the CVPR publication year, 2016. No Zotero item keys or personal project assignments are invented.

Architecture figures in `assets/` are cropped from the cited original papers; each figure is attributed in its example note. The original source PDFs are not redistributed in this repository. These summaries are independent explanatory notes, not author-provided reviews. The plugin creates a page outline; it does not automatically read or summarize papers.

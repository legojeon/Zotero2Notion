# Changelog

## 0.1.10 — 2026-10-22

First public GitHub release.

- Automatically sync personal-library metadata into Notion using a personal access token.
- Create a private JournalDB or select an existing database.
- Edit Markdown templates in Zotero settings with autosave; choose templates by collection or tag.
- Include English Paper review and Section summary outlines and completed examples.
- Preserve existing page notes and reading status during metadata updates.
- Provide an approved logo, public template link, MIT license, and GitHub-hosted update manifest.

Earlier 0.1.x versions were local development builds. Install this XPI once to enable the public update URL.

# Logo

`logo.png` is the original transparent PNG approved on 2026-10-22. Keep this source unchanged. The plugin uses size variants in `addon/icons/` (24, 48, 96, and 256 pixels), referenced by `addon/manifest.json`. Zotero uses the manifest icon in Plugins Manager and the settings sidebar.

The source was created with the built-in image generation tool. Only resizing was applied to produce installation assets; the approved design was not regenerated.

Design prompt: a minimal black-and-white Notion notebook/block icon, with its N replaced by a large red Zotero-style Z, and matching red sticky-note tabs emerging from the top and right edges. Transparent background; no caption or product name.

Connector로 논문 저장하기

Zotero Connector는 브라우저에서 논문 정보를 읽어 Zotero에 저장합니다. Zotero2Notion은 그 문헌을 연결한 Notion 데이터베이스에 동기화합니다. 먼저 플러그인 설치와 Notion 연결을 마쳐 주세요.

  1. 브라우저에 Connector를 설치하세요.

    Chrome, Firefox, Edge에서는 Zotero 공식 다운로드 페이지에서 사용하는 브라우저용 확장 프로그램을 설치하세요. Safari에서는 Zotero에 포함된 확장을 Safari 설정 → 확장 프로그램에서 켜세요.

  2. 논문 상세 페이지에서 저장하세요.

    Zotero 데스크톱 앱을 켜고 브라우저에서 논문의 초록이나 서지 정보가 보이는 페이지를 여세요. 도구 막대의 Save to Zotero를 누른 뒤 저장 창에서 My Library 또는 그 안의 컬렉션을 선택하세요. Zotero의 웹 저장 안내

  3. Notion에 같은 논문이 있는지 확인하세요.

    Zotero에서 방금 저장한 문헌의 제목과 저자를 확인하세요. 앱을 열어 둔 상태에서 연결한 Notion 데이터베이스를 열고 같은 제목을 찾아보세요. 함께 저장된 PDF는 Zotero에 남고, 매핑한 서지 정보가 Notion에 들어갑니다.

어느 단계에서 멈췄나요?

Zotero에 문헌이 없을 때는 데스크톱 앱을 켠 뒤 브라우저를 다시 열어 보세요. Connector 연결 문제 해결

Zotero에만 문헌이 있을 때는 개인 라이브러리의 일반 문헌인지 확인하세요. 그룹 라이브러리나 단독 PDF 첨부 파일은 동기화 대상에서 제외됩니다. 플러그인 설정에서 선택한 데이터베이스와 Check properties 결과도 확인하세요.

노트 템플릿 만들기

읽을 때마다 같은 질문을 던진다면 그 질문을 템플릿에 넣어 보세요. 플러그인이 새 논문 페이지를 만들 때 제목과 저자를 채우고, 그 아래에 답을 쓸 자리를 마련합니다.

  1. 편집할 템플릿을 만드세요.

    Zotero에서 Settings → Zotero2Notion → Templates를 여세요. Edit template 옆의 New를 누르거나, Paper review를 선택하고 Duplicate로 사본을 만드세요. Name에 ‘나의 논문 노트’를 입력하세요.

  2. Markdown 편집기에 예제를 붙여 넣으세요.

    [title], [authors], [year] 자리에는 문헌의 제목, 저자, 연도가 들어갑니다. ##로 시작하는 소제목은 평소 기록하는 질문으로 바꿔 보세요. 변경 사항은 자동으로 저장됩니다.

    문헌에 딸린 Zotero 노트도 가져오려면 다른 내용이 없는 줄에 [zotero_notes]를 넣으세요. 템플릿 전체에서 한 번만 사용합니다. 가져온 노트는 이후에도 갱신되므로 직접 쓸 메모는 해당 토글 바깥에 두세요.

  3. 미리 보고 기본 템플릿을 정하세요.

    Preview에서 선택한 문헌의 제목과 저자가 채워지는지 확인하세요. 선택한 문헌이 없으면 예제 데이터가 표시됩니다. Default template에서 ‘나의 논문 노트’를 고른 뒤, 새 문헌을 저장해 Notion에 생긴 본문을 확인하세요. 템플릿을 수정해도 이미 작성한 페이지의 본문은 유지됩니다.

컬렉션마다 다른 노트를 쓰려면

Template rules → Add rule에서 Collection을 고르고 원하는 컬렉션과 템플릿을 지정하세요. 이 규칙은 하위 컬렉션에도 적용됩니다. Tag로 규칙을 만들 때는 태그 이름을 정확히 입력하세요. 여러 규칙에 해당하면 위에서부터 처음 일치하는 규칙을 사용합니다.

Notion 데이터베이스의 보기까지 가져오려면

예제 페이지와 보기가 담긴 공개 Journal DB 템플릿을 열고 복제(Duplicate)를 눌러 토큰을 발급한 워크스페이스에 복사하세요. 복사본에서는 Status별로 그룹화한 보기를 추가해 읽기 진행 상황을 볼 수 있습니다.

Zotero2Notion 설정에서 Refresh를 누르고 복사한 데이터베이스를 골라 Use를 누르세요. Check properties에서 속성 연결을 확인하면 이후 동기화에 이 데이터베이스를 사용합니다. 각 논문 페이지의 본문은 위에서 정한 Markdown 템플릿을 따릅니다.

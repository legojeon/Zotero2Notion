활용 팁

논문 제목과 저자는 Zotero에서 가져오고, Notion 노트에는 평소 자주 쓰는 메모 항목을 미리 넣어 둘 수 있습니다.

브라우저에서 논문 저장하기

브라우저에서 Zotero Connector로 논문을 저장하면 Zotero2Notion이 제목과 저자 등 논문 정보를 Notion으로 보냅니다. 처음 사용한다면 Zotero2Notion을 설치하고 Notion에 연결하세요.

  1. 브라우저에 Zotero Connector 설치하기

    Chrome, Firefox, Edge를 쓴다면 Zotero 다운로드 페이지에서 브라우저에 맞는 Connector를 설치하세요. Safari용 Connector는 Zotero에 포함되어 있으니 Safari 설정 → 확장 프로그램에서 켜면 됩니다.

  2. 논문 페이지에서 Zotero에 저장하기

    Zotero 데스크톱 앱을 켜 둔 채 브라우저에서 논문 제목과 초록이 나오는 페이지를 여세요. 도구 모음에서 Save to Zotero를 누르고 저장할 위치로 My Library나 그 안의 컬렉션을 고르세요. Zotero의 웹 저장 안내

  3. Notion에서 논문 찾기

    Zotero에 제목과 저자가 제대로 들어왔는지 확인하세요. Zotero 앱을 열어 두면 연결한 Notion 데이터베이스에서도 같은 제목으로 논문을 찾을 수 있습니다. 제목, 저자 등 설정에서 연결한 항목이 동기화되고 PDF 파일은 Zotero에 남습니다.

저장한 논문이 보이지 않을 때

Zotero에도 없다면 데스크톱 앱을 켜고 브라우저를 다시 시작하세요. Connector 연결 문제 해결 방법

Notion에만 없다면 논문이 개인 라이브러리에 문헌 항목으로 저장됐는지 확인하세요. 그룹 라이브러리의 논문이나 단독으로 저장한 PDF는 동기화하지 않습니다. 플러그인 설정에서 연결된 데이터베이스를 확인하고 Check properties를 눌러 필요한 속성이 있는지도 살펴보세요.

노트 템플릿 만들기

‘연구 질문’, ‘내 연구에 적용할 점’처럼 논문을 읽을 때마다 적는 항목은 템플릿에 넣어 두세요. 새 논문을 저장하면 제목과 저자가 채워진 노트에 바로 메모할 수 있습니다.

  1. 템플릿 추가하기

    Zotero에서 Settings → Zotero2Notion → Templates를 열고 Edit template 옆의 New를 누르세요. 기존 예제를 고쳐 쓰려면 Paper review를 고른 뒤 Duplicate를 누르면 됩니다. Name에 ‘나의 논문 노트’처럼 알아보기 쉬운 이름을 입력하세요.

  2. 노트에 쓸 항목 정하기

    아래 예제를 Markdown 편집기에 붙여 넣으세요. [title], [authors], [year]에는 논문의 제목, 저자, 출판 연도가 자동으로 들어갑니다. ## 뒤에는 평소에 기록하는 항목을 적으세요. 편집한 내용은 자동으로 저장됩니다.

    논문에 달아 둔 Zotero 노트도 가져오려면 빈 줄에 [zotero_notes]만 적으세요. 템플릿에 한 번만 넣으면 됩니다. 가져온 노트는 계속 동기화되므로 Notion에서 새로 쓰는 메모는 해당 토글 밖에 적으세요.

  3. 미리 보고 기본 템플릿으로 지정하기

    Preview를 누르면 Zotero에서 선택한 논문으로 결과를 미리 볼 수 있습니다. 논문을 선택하지 않았다면 예제 데이터가 나옵니다. Default template에서 방금 만든 템플릿을 고르고 새 논문을 저장해 보세요. 새 Notion 페이지에 이 양식이 적용되고, 기존 페이지에 쓴 내용은 그대로 남습니다.

컬렉션이나 태그마다 다른 템플릿 쓰기

Template rules → Add rule에서 Collection을 고른 뒤 컬렉션과 그 컬렉션에서 쓸 템플릿을 지정하세요. 하위 컬렉션에도 같은 규칙이 적용됩니다. 태그를 기준으로 정하려면 Tag를 고르고 Zotero에 등록한 태그 이름을 그대로 입력하세요. 여러 규칙이 한 논문에 해당하면 그중 가장 위에 있는 규칙을 따릅니다.

Notion 데이터베이스 템플릿 복제하기

Journal DB 템플릿을 열고 복제(Duplicate)를 누르세요. 토큰을 발급한 워크스페이스를 고르면 예제 페이지와 데이터베이스 보기가 함께 복사됩니다. 복사본에 Status로 그룹화한 보기를 추가하면 읽는 중인 논문과 다 읽은 논문을 나눠 볼 수 있습니다.

Zotero2Notion 설정으로 돌아와 Refresh를 누르세요. 목록에서 복사한 데이터베이스를 고르고 Use를 누른 뒤 Check properties로 필요한 속성을 확인하세요. 이제 새 논문은 이 데이터베이스에 저장되고, 각 논문의 본문에는 앞에서 설정한 노트 템플릿이 적용됩니다.

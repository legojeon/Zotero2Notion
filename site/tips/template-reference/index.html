노트 템플릿 만들기로 돌아가기

템플릿 변수와 규칙

논문 노트에 자동으로 채울 항목을 고르고, 컬렉션이나 태그에 따라 어떤 템플릿을 쓸지 정하세요.

목차 기본 변수 데이터베이스 속성 템플릿 선택 규칙

기본 변수

Zotero의 Settings → Zotero2Notion → Templates에서 Markdown 본문에 변수 이름을 대괄호와 함께 적으세요. 예를 들어 [title] ([year])는 Attention Is All You Need (2017)로 표시됩니다. Zotero에서 논문을 선택하고 Preview를 누르면 그 논문으로 미리 볼 수 있습니다.

변수노트에 들어가는 내용
[title]논문 제목. 기본 속성 [Journal Name]과 같은 값입니다.
[authors]전체 저자 이름. 여러 명이면 세미콜론으로 구분합니다.
[authors_short]첫 번째 저자 이름. 공저자가 있으면 뒤에 et al.이 붙고, 저자 정보가 없으면 Unknown author로 표시됩니다.
[year]출판 연도
[url]논문 주소를 URL 그대로 표시합니다.
[paper_link]논문 주소로 연결되는 Paper 링크. 주소가 없으면 Paper URL unavailable로 표시됩니다.
[zotero_link]Zotero 라이브러리의 해당 문헌으로 연결되는 Zotero 링크
[zotero_notes]해당 문헌에 작성한 Zotero 노트를 넣을 자리

[zotero_notes]는 코드 블록 밖에서 한 줄에 단독으로, 템플릿 전체에 한 번만 적으세요. 노트가 여러 개면 Zotero Notes 안에서 하나씩 펼쳐 볼 수 있습니다. 가져올 노트가 없으면 이 섹션은 생기지 않습니다. 가져온 노트는 계속 동기화되므로 Notion에서 직접 쓰는 메모는 토글 밖에 적으세요.

데이터베이스 속성

초록을 넣으려면 [Abstract], 참고문헌 표기를 넣으려면 [Full Citation]처럼 속성 이름을 그대로 적으세요. 영문을 소문자로 쓰고 공백이나 하이픈을 밑줄로 바꿔도 됩니다. [full_citation]과 [in_text_citation]이 그런 예입니다.

분류템플릿에 쓸 수 있는 기본 속성
논문 정보[Journal Name], [Short Title], [Authors], [Editors], [Abstract], [Item Type]
출판 정보[Publication], [Proceedings Title], [Series Title], [Place], [Year], [Date]
인용 정보[DOI], [Citation Key], [Full Citation], [In-Text Citation]
링크와 파일[Paper URL], [Zotero URI], [Zotero Key], [File Path]
분류와 읽기 상태[Tags], [Collections], [Project], [Status]
기타 정보[Date Added], [Date Modified], [Extra]

직접 만든 속성 쓰기

기본 속성을 Notion에서 다른 이름으로 연결했다면 두 이름 모두 쓸 수 있습니다. 직접 추가한 속성도 마찬가지입니다. 예를 들어 텍스트 속성 ‘읽는 이유’는 [읽는 이유] 또는 [읽는_이유]로 넣으세요. Preview에서는 Zotero 문헌이나 예제 데이터를 사용하므로 Notion 속성값은 새 논문 페이지에서 확인하세요.

제목, 텍스트, 숫자, 선택, 상태, 다중 선택, 날짜, 체크박스, URL, 생성·수정 시간 속성을 지원합니다. 날짜 범위에서는 시작일을 가져오고, 다중 선택 항목은 세미콜론으로 구분합니다.

페이지 본문을 처음 채울 때 속성값을 한 번 가져옵니다. 관계형·롤업·수식 속성은 빈칸으로 표시됩니다. 변수 이름에 오타가 있으면 대괄호가 그대로 남습니다.

템플릿 선택 규칙

Templates → Default template에서 평소 쓸 양식을 고르세요. Edit template은 편집할 양식을 여는 메뉴입니다. 특정 컬렉션이나 태그에 다른 양식을 쓰고 싶다면 규칙을 추가하세요.

  1. Template rules → Add rule을 누르세요.
  2. Collection을 고르면 선택한 컬렉션과 그 아래의 모든 컬렉션에 적용됩니다. 컬렉션 이름을 바꿔도 규칙은 유지됩니다. Tag를 고르면 Zotero에 등록한 태그 이름을 대소문자까지 똑같이 입력하세요.
  3. Template에서 이 조건에 쓸 양식을 고르세요. ↑를 누르면 규칙이 한 칸 올라갑니다.

태그와 컬렉션이 모두 일치하면?

맨 위에 review 태그용 Paper review 규칙을 두고, 그 아래에 Seminar 컬렉션용 Section summary 규칙을 두세요. 그러면 같은 세미나 논문이라도 review 태그가 붙은 논문에는 Paper review가, 그 태그가 없는 논문에는 Section summary가 적용됩니다.

플러그인은 위에서부터 처음 일치하는 규칙 하나를 적용합니다. 설정을 마치지 않았거나 비활성인 규칙은 건너뜁니다. 어느 규칙에도 맞지 않으면 기본 템플릿을 씁니다. 규칙을 바꾸면 이후 만드는 노트에 적용되고, 이미 작성한 본문은 그대로 남습니다.

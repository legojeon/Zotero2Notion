Installation guide

You’ll need Zotero 10.0.x and a Notion account that can create a personal access token.

  1. Install the plugin in Zotero

    Download the .xpi file above. In Zotero, open Tools → Plugins. Open the gear menu, choose Install Plugin From File…, and select the downloaded file.

  2. Connect your Notion account

    In Zotero, open Settings → Zotero2Notion and click Get token. Choose your workspace in Notion and create a personal access token with the Notion API capability.

    Back in the plugin settings, paste the token into Personal access token and click Connect.

  3. Choose a database

    To start with an empty database, click New. The plugin creates JournalDB under a private Zotero2Notion page in your workspace.

    To use an existing database or a copy of the example Notion template, click Refresh, select the database, and click Use. Open Check properties to see which properties it needs.

    Your first sync

    Once the properties are ready, sync starts automatically, including papers already in My Library. Keep Zotero open to sync new papers and edits.

FAQ

Full user guide
Which Zotero data syncs to Notion?

The plugin syncs the fields you map for items in My Library, including titles, authors, abstracts, tags, and collections. Add [zotero_notes] on its own line in your template to include a paper’s child notes. Group libraries, PDF files, and annotations that exist only in a PDF are outside the scope of sync.

What happens to the notes I write in Notion?

The plugin applies your template when it creates a page. Later updates to the paper’s details preserve your writing and reading status. The plugin updates imported Zotero notes separately, so keep your own writing outside their toggles.

Why can’t I see my database?

Check that the database belongs to the workspace where you created the token. In the plugin settings, click Refresh. Select the database when it appears, then click Use to connect it.
